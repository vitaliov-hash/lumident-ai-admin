# Правила работы с проектом LumiDent

После каждого существенного изменения проекта проверь и при необходимости обнови `PROJECT_CONTEXT.md`.

В `PROJECT_CONTEXT.md` фиксируй:

- реализованные функции;
- важные изменения архитектуры;
- используемые AI-модели и API;
- изменения системного промта;
- текущее состояние проекта;
- следующие задачи.

Не записывай в `PROJECT_CONTEXT.md` API-ключи, пароли, токены, содержимое `.env` и другие секреты.
