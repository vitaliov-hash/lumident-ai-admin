# LumiDent

LumiDent — цифровой администратор стоматологической клиники. Посетители используют гостевой чат без регистрации на странице `/user`. Администратор входит отдельно на `/admin` под учётной записью с ролью `admin`. Публичная регистрация отключена.

Проект локально развивается: гостевой режим, английский интерфейс, голосовой ввод и озвучка ответов подготовлены в текущих изменениях, но пока не опубликованы на GitHub/Render. Не используйте приложение для реальных данных пациентов без отдельной правовой и эксплуатационной проверки. Реальная запись в календарь и передача заявки клинике не подключены.

## Локальный запуск

Требуется Node.js 20 или новее.

1. Установите зависимости командой `pnpm install` (или используйте установленный в окружении менеджер пакетов).
2. Скопируйте `.env.example` в `.env` и заполните необходимые значения только локально.
3. Чтобы включить Pro с PostgreSQL, настройте `DATABASE_URL`; для ответов AI задайте `DEEPSEEK_API_KEY`. Не передавайте секреты в чат и не коммитьте `.env`.
4. Запустите `pnpm start` и откройте `http://127.0.0.1:3000/user`.

Без `DATABASE_URL` работает локальный fallback гостевого чата и справочника; авторизация администратора и постоянная админ-панель требуют Pro PostgreSQL. DeepSeek подключается только сервером. Без ключа используется справочный fallback. Браузерные API распознавания речи и синтеза доступны не во всех браузерах; текстовый ввод остаётся доступен всегда.

## Ссылки и данные

- `/user` — гостевой чат без учётной записи; история диалога хранится только в памяти открытой страницы.
- `/admin` — отдельный вход администратора; публичной формы регистрации нет.
- `/api/knowledge` — актуальные услуги и часы, используемые каталогом.
- `/api/chat` — гостевой AI-чат с ограничениями на длину и частоту запросов.
- `SYSTEM_PROMPT.md` — правила поведения AI.
- `PROJECT_SPEC_PRO.md` — актуальное направление развития и критерии проверки.
- `PROJECT_CONTEXT.md` — синхронизируемый контекст проекта для ChatGPT и Codex.

Для production-режима требуется PostgreSQL, настроенная через `DATABASE_URL`. Точный список переменных без значений секретов находится в `.env.example`. Назначение роли администратора выполняется защищённой процедурой, а не через публичную регистрацию.

## Безопасность

- Никогда не добавляйте `.env`, ключи, пароли, токены и строки подключения в Git, документацию или скриншоты.
- DeepSeek API key читается только backend-сервером.
- Гостевые сообщения не сохраняются в БД.
- Ошибки AI API обрабатываются с понятным сообщением для посетителя.

## Автоматические проверки

Запустите `pnpm test`. Набор `test/server.test.js` поднимает изолированный fallback-сервер без DATABASE_URL и DeepSeek, затем проверяет публичные страницы, RU/EN каталог, пять типовых вопросов и ошибки некорректного ввода. Тесты не подключаются к production Neon и не вызывают платный AI API.

Для интеграционной проверки PostgreSQL/ролей используйте отдельную тестовую Neon branch и добавьте её URL локально в `.env` как `LUMIDENT_TEST_DATABASE_URL=...`, затем запустите `node --test test/pro-integration.test.js`. Этот набор мигрирует тестовую базу, создаёт временные тестовые аккаунты/услугу и удаляет их после завершения. Не направляйте его на production-ветку и не присылайте URL в чат.
