# LumiDent — AI-администратор стоматологии

Адаптивный демонстрационный сайт с чатом, примерным каталогом услуг и приёмом демо-заявок. Адрес, телефон, сайт, цены и гарантии придуманы для прототипа.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов не требуется.

1. Скопируйте `.env.example` в `.env` в корне проекта.
2. Для подключения DeepSeek вставьте значение ключа **только в локальный `.env`** после `DEEPSEEK_API_KEY=`. В чат, Git и frontend ключ не отправляйте. Переменная `LLM_API_KEY` больше не используется.
3. При необходимости измените `LLM_BASE_URL` и `LLM_MODEL`.
4. Запустите `npm start` и откройте `http://127.0.0.1:3000`.

Без ключа сайт работает в явно отмеченном **деморежиме**. Это набор примерных ответов для проверки интерфейса и пяти сценариев, не обращение к LLM. С ключом вопросы поступают в DeepSeek через серверный маршрут `/api/chat`. После добавления ключа проверен настоящий ответ DeepSeek на вопрос о стоимости лечения кариеса.

## Заявки

Напишите «Хочу записаться на приём». Агент по очереди запросит имя, телефон, услугу, удобные день и время, затем попросит проверить сведения. Демо-заявка хранится **только в памяти сервера** до перезапуска и никому не отправляется. Реальную запись нужно подтверждать через администратора клиники. Админ-панели в этой версии нет.

## Безопасность и ошибки

- Ключ читается только сервером из `DEEPSEEK_API_KEY`; во frontend не передаётся.
- `.env` исключён через `.gitignore`. Не добавляйте его в архив и репозиторий.
- Сервер проверяет входящие сообщения и ограничивает размер запроса.
- При ошибке провайдера, таймауте (12 секунд) или пустом ответе API возвращает понятное сообщение; интерфейс продолжает работать.
- Секреты и технический текст исключений не включаются в ответы API и логи.

## Структура

- `server.js` — сервер, маршрут чата и логика демо-заявок;
- `SYSTEM_PROMPT.md` — системный промт из четырёх блоков;
- `public/` — адаптивный интерфейс и иллюстрация зуба;
- `.env.example` — шаблон настроек.

## Проверка

Все пять вопросов проверены через подключённый DeepSeek. Ответы и результаты приведены в `TEST_REPORT.md`, скриншоты лежат в `screenshots/`. При активном подключении в чате отображается «DeepSeek на связи».
